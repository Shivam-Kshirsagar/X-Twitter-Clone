📌 About The Project

This project is a frontend clone of X (formerly Twitter).
It is created to practice and demonstrate modern web development concepts using HTML and Tailwind CSS.

✨ Features
🐦 X (Twitter)-inspired user interface
📱 Responsive design
🏠 Home feed interface
🔍 Search and navigation sections
👤 Profile and sidebar sections
🎨 Modern and clean UI
⚡ Fast and lightweight
🌐 Works across modern browsers
🛠️ Technologies Used
HTML5
Tailwind CSS
JavaScript
Git & GitHub
